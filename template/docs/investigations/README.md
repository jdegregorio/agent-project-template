# Investigations

Use this directory for bounded research, incident analysis, performance work, and difficult debugging. These notes are evidence, not automatically current truth.

Name records `YYYY-MM-DD-short-topic.md` and include:

- Question or symptom
- Scope and environment
- Evidence gathered
- Hypotheses considered
- Findings and confidence
- Decision or recommended next step
- Unresolved questions

Promote durable outcomes into specifications, architecture, operations, or decision records and link back to the investigation.
