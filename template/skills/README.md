# Project skills

This directory is for skills that encode knowledge or workflows specific to this project.

Good project-local candidates include:

- domain terminology and invariants
- framework workflows that are unusual in this repository
- deployment or incident procedures unique to this system
- specialized test or data-generation workflows

Keep broadly useful engineering skills in the global environment. Do not copy experimental skills here merely because they are available; add a skill only when it materially improves repeated work on this project.

Each skill should have a narrow trigger, a clear source of truth, and a validation path. Remove or update skills when the project knowledge they encode changes.
